처음 한 번: GitHub 토큰 연결

  1. github.com/settings/personal-access-tokens/new 열기 (Fine-grained token)
  2. Token name: 아무거나 (예: homepage-admin), Expiration: 원하는 기간 (최대 1년, 만료되면 다시 발급)
  3. Repository access → Only select repositories → 선택
  4. Permissions → Add permissions 버튼 → Contents 선택 → 오른쪽 드롭다운을 Read and write로 (Metadata가 같이 생기면 그대로 둠)
  5. Generate token → 나오는 github_pat_… 문자열을 아래에 붙여넣기
토큰은 이 브라우저(localStorage)에만 저장됩니다. 다른 컴퓨터에서는 다시 붙여넣어야 해요.
